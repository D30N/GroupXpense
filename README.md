# Group Xpense - track & split

Track group expenses and split bills with friends — trips, roommates, dinners, events. Everything works fully offline, right on your phone. No account, no ads.

## Features

- Create groups with members and your own currency (₹, $, € and more)
- Add expenses with equal or custom splits
- Advance payments for future costs
- Balances with a clear "who should pay whom" settle-up list — tap to record a settlement
- Categories with totals, plus custom categories
- Beautiful PDF reports and shareable text summaries
- Receipt photo attachments
- 13 theme colours + a custom colour picker, dark / light / system modes
- Backup & restore (export / import)
- Currency converter
